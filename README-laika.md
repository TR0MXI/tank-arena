# 莱卡（Laika）· 网页版普通弹行为移植

这是独立的单文件 Luau 陪练。源码在 `assets/strategies/laika.luau`；把它复制为可写车库中的 `bots/Laika.luau`（macOS 发布版在 `.app` 旁），在阵容中选择 **莱卡（Laika）**。它和 Avalon 读同一份全图 `obs`、运行在相同的 Luau 沙箱中，只提交 `drive`、`turn`、`fire`。不修改裁判，不需要联网，也不取代默认示例。

## 参照与范围

2026-11-23 核对 [TankTrouble 官网](https://tanktrouble.com/) 对外提供的 `RELEASE-2026-11-19-01`，参照该版本网页客户端 `index-YEK2KFUM.js` 的 AI 目标、动作、迷宫和弹道查询。客户端的 `tanktrouble.getAIs` 返回 Laika 的聪明度 0.4、灵巧度 0.6、大胆度 0.9、执着度 0.6、攻击性 0.9、贪心度 0.2、复仇心 0.8。参考对象是**只装备默认普通炮弹**、没有道具/特殊区域影响的 Laika，不是 Flash 版，也不是以对 Avalon 的胜率为优化目标。

| 决策环节 | 此移植的做法 |
| --- | --- |
| 目标竞争 | 躲弹、射击、弹槽全占时撤离、脱困、追击、闲逛按优先级竞争。四邻迷宫步数 `< 5` 才提出主动射击目标，无遮挡也不例外。约 520 ms 的目标保持期后，旧目标的优先级按执着度衰减；没被新目标替代时继续原队列。攻击欲从零增长，选定主动射击或还击就下降，不是命中才下降。 |
| 直射与反弹 | 中心视线畅通时面向目标；被墙挡住时，以**当前车头**为中心取 3 条带抖动的射线，最大长度 4.4 格，最多 3 次反射。不再镜像敌人找精确反弹角。优先选较短的命中路线，其次比较对敌人的最近可见距离，近失也可开火。不选会先撞自己或首段过短的反弹；没有可用路线会转头重试。 |
| 预判与寻路 | 遍历场上炮弹，按迷宫距离和聪明度选择要展开的路径（不是隐去远处的观察）。跟踪最近可见接近点、来向和到达时间。把预测弹道、敌车炮口方向及其周围格子记为危险；追击时权衡危险和路程，可沿畅通方格走对角线，但不切墙角。 |
| 闪避与撤离 | 迫近的弹道旁，比较两侧脱离点与挡墙，允许倒车，随后对齐弹道方向；不紧迫时根据来弹所在格、危险程度和死胡同代价选择撤离路线。空仓时看所有敌车的平均迷宫距离，不是一律远离最近的那辆。躲弹/撤离时原炮口若有还击机会，可把短延迟开火插到队首。 |
| 按键节奏 | 追踪一个明确的转向、行驶、等待或开火动作，而非每帧重瞄。普通主动射击延迟约 120 ms，还击约 40 ms；按下并松开扳机，只产生一次上升沿。随机偏差由公开的 `behavior_seed` 在每个席位独立生成；没有 seed 时也可重复。 |

## 哪些仍不是逐帧等价

- 官网直接查询 Box2D。本地脚本根据公开的墙、车身和炮塔尺寸计算射线；墙角同时接触的处理、危险格内按段中点计算时间权重与官网离散采样有差异。脱困时没有墙碰撞事件的接触法线，用实际位移受阻和行驶方向估计退出方向。
- 本地有队友及友伤，选敌时排除队友，按下扳机前还会拒绝当前路线中预测的友伤或自伤。自己的弹在首次反弹前不算近身躲避目标。
- 不复用官网的随机流、Box2D 时间步或寻路平局顺序。为减少单次决策耗时，繁重规划基于一份冻结的观察分多次完成，期间继续执行上一个**完整**队列。密集弹幕下，目标生效可能晚几步。
- 本地每场单独创建 VM、死亡即淘汰，没有跨回合击杀历史或死斗积分榜，因而没有假造“复仇对象”或“积分领先者”。没有拾取物、护盾、陷阱、特殊武器或区域目标。没有为这些差异新增专用 API。

## 如何验证

`cargo test --test laika` 在正式 Luau VM 和本地裁判上运行。为区分“行为像”和“这组输入确实对得上”，还单独在临时环境调用过上述发行版的原始目标选择器和动作队列：提供两辆静止坦克、普通弹、无来弹/道具、直廊迷宫距离，时钟为 60 Hz。在直射样例固定瞄准误差为零；本地测试不关闭随机误差（它在转向死区内）。**这是判定分支的受控对照，不是两套完整游戏同步运行。** 不在仓库里分发官网脚本。

| 条件 | 官网受控对照 | 本地回归断言 |
| --- | --- | --- |
| 满弹，无遮挡，距离 4，炮口对准 | 选择射击；以首次观察为 tick 0，扳机在 9、10 和 42、43 为按下 | 固定车位和弹量，逐 tick 核对按键和 9、42 两个上升沿 |
| 满弹，无遮挡，距离 5 或 7 | 选择追击；不是看见就开火 | 前进且不按扳机 |
| 空仓，距离 4 | 选择撤离 | 在真实对局先打出五发、保持来弹远离，再验证拉开距离 |

其余场景验证：同一颗弹在无直射时反弹命中；躲过会击毁静止车的敌弹及自己的回弹；仅翻转敌方炮口会改变绕墙路线；不穿过挡线的队友开火；固定种子重复同一序列、不同种子能给出不同扇形决策；8 车 40 弹冷启动后跨多 tick 完成规划。
