# 道具箱

在「开始对局 → 地图与时限」下方的「道具管理」选择箱子，查看其缩写、效果和数据，再决定是否启用。九种箱子默认全开；开关保存在本机偏好中。关闭全部后不再生成箱子，不影响普通炮弹或既有录像。

- 以比赛时间计，每隔 3–8 秒尝试刷新一箱，场上最多三箱。只从启用的种类中等概率选择。坦克碰到箱子即拾取。
- 拾取的武器按顺序使用，最多同时携带三件（含当前武器）；用尽后切到下一件或回到普通炮。护盾和加速立即生效，不占武器位，同种效果不叠加。
- 激光可预览反弹路线；双管炮逐次交替发射；霰弹枪每轮打出 20 枚弹丸；导弹发射两秒后沿迷宫寻敌，也可能转回来追自己。地雷向后布设，武装后触碰会引爆。加特林需要**按住**开火；破片炸弹需要**松开再按**才能主动起爆。
- 护盾反弹来弹，持续 6 秒。加速持续 10 秒，使移动、转向、普通炮弹和双管炮弹速度提高 30%，不加快装填。

## Luau 观察

`obs.crates` 是只读列表，每行有 `kind`、`x`、`y`，和坦克坐标一样以每格 1024 为单位。种类为 `laser`、`doubleBarrel`、`shotgun`、`homingMissile`、`mine`、`gatling`、`fragBomb`、`shield`、`speedBoost`。

`obs.me` 和 `obs.tanks` 的行含 `weapon`（普通炮为 `nil`）、`shield_ticks`、`speed_ticks`。`obs.ammo` 是当前武器的可用次数（已发射但可以遥爆的破片炸弹算一次）；`obs.ammo_limit` 仍指普通炮的五个弹槽。加特林在可持续按住扳机时也会报告 `can_fire`。`obs.shells` 的行增加 `kind`，可以区分普通炮弹 `bullet`、弹丸 `pellet`、破片 `shard` 等。地雷也在此列表内，不能只按直线飞行的子弹处理。

`obs.weapon_slots_used` 是**本席**已经占用的武器位数（0–3，包含当前武器）。用它区分“暂时没有子弹”和“武器队列没有空位”；不会公开其他坦克的队列长度。护盾和加速不占这些位置。
